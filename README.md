# Walmart — Generative AI Training for Engineering Managers

Hands-on notebooks for the Walmart × upGrad Generative AI programme for Engineering Managers.

## Contents

| Folder | Contents |
|---|---|
| `Day_1/` | Accessing models and APIs, prompting foundations |

More folders (`Day_2/`, `Day_3/`, …) are added as the programme progresses.

## How to run

1. Open a notebook in Jupyter, or click the **Open in Colab** badge below.
2. Where a notebook asks for an API key, paste the key shared with you in the session.
   Keys are **not** committed to this repository.

## Running in Google Colab

Replace `<PATH>` with the notebook path, e.g. `Day_1/E01_Accessing_Models_and_APIs.ipynb`:

`https://colab.research.google.com/github/sudhanshusaxena/walmart-genai-engineering-managers/blob/main/<PATH>`
